| String Literal           | Primitive string value                                    |

| Callback Function        | Function passed as an argument                            |
| Higher Order Function    | Accepts or returns another function                       |

# 📚 Best Practices

* Prefer array helper methods (`map`, `filter`, `reduce`) for cleaner code.
* Avoid mutating arrays unless necessary.
* Use string literals instead of the `String` constructor.
* Write small, reusable functions with a single responsibility.
* Prefer arrow functions where appropriate.
* Avoid callback nesting by using Promises or Async/Await.
* Use `async/await` for better readability and maintainability.
* Always handle Promise rejections using `catch` or `try...catch`.
