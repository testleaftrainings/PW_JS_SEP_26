Since this project is a Playwright + TypeScript automation framework, the interviewer may ask questions from these areas:

1) Framework understanding
What is this framework?
Why have you used Playwright here?
What is the purpose of the Page Object Model in this project?
How is the project structured?
What is the role of the config file?
2) Playwright-specific questions
What is Playwright and why is it better than Selenium?
What is auto-waiting in Playwright?
How do you handle dynamic elements?
What is the difference between locator and selector?
What is trace, screenshot, and video in Playwright?
How do you handle frames, alerts, and popups?
What is headless mode?
3) Page Object Model questions
What is POM?
Why is POM useful?
What is the benefit of keeping page logic separate from test logic?
How do you design a page class?
4) Test design questions
What is a test case flow in this framework?
How do you create a new test for a feature?
How do you handle test data?
What is data-driven testing?
How do you generate random data for test execution?
5) Fixture and setup questions
What is a custom fixture in Playwright?
Why are fixtures useful?
How do you reuse login across multiple test cases?
How do you initialize a browser session?
6) API testing questions
What is the role of Axios in this framework?
How do you validate API responses?
What is JWT or access token generation?
How do you check status codes and response bodies?
Why is API testing useful along with UI testing?
7) Reporting and debugging questions
How do you debug failures in Playwright?
What is Allure report?
What is HTML reporting?
How do you capture screenshots and video logs?
What information is helpful in a failing test report?
8) Data handling questions
How do you read data from CSV, JSON, Excel?
Why is externalized test data important?
What is Faker and why is it used?
9) Best practices questions
What are the best practices in automation testing?
How do you handle flaky tests?
How do you choose locators?
Why should we avoid hardcoded waits?
How do you maintain automation scripts in large projects?
10) Scenario-based questions
If a login test fails due to a flaky locator, what will you do?
If the page loads slowly, how will you handle it?
If same test runs in multiple browsers and fails in only one browser, what will you check?
How will you design a framework for a new application?
